# Qwen 125B — SC117 на компьютере друга

Отдельный проект для запуска **Qwen3.8-Flash-Next 125B Abliterated IQ3_XXS (SC117)** через **Strata** на Windows-компьютере друга, с управлением через ChatGPT → MCP → Cloudflare Tunnel.

**Решение от 19.11.2026:** только последний сценарий **домашний компьютер друга**. Старые проекты по аренде GPU, TensorDock, 27B и другие серверные варианты не относятся к этому проекту.

**Текущий статус:** отдельный приватный GitHub-репозиторий создан; MCP-сервер, туннель, установщик и модель ещё НЕ развёрнуты. Живых тестов нет.

## Устройство (сообщено владельцем)
- NVIDIA RTX 3090 Ti, 24 ГБ VRAM.
- Intel Core i9-12900K.
- 64 ГБ DDR5 4800 MT/s.
- NVMe C:/D:, **свободный объём неизвестен**.
- Windows; версия и права установки проверяются на самом ПК.
- Владелец компьютера дал согласие на удалённое управление.

## Решение по архитектуре
- **Один MCP-сервер прямо на Windows, без отдельного продукта «Windows-агент».**
- Существующая учётная запись Windows; нового пользователя не создаём.
- Приватный удалённый MCP ChatGPT через защищённый HTTPS, авторизацию и отдельный Cloudflare Tunnel.
- Один установщик: друг скачивает → запускает и подтверждает UAC → проходит одноразовую привязку. Дальше администрирование удалённо.
- Перед передачей установщика максимально готовим инфраструктуру, исходники, тесты и документацию.
- Два режима: **ИИ / Игры**, переключение без самовольного закрытия игр/других программ.

## Модель
Источник: https://huggingface.co/SC117/Qwen3.8-Flash-Next-GSQ-RCO-abliterated-GGUF

Движок: https://github.com/Niko1221/Strata

Квантование IQ3_XXS, предполагаемый объём загрузки около 76 ГБ (GGUF около 47 ГБ и n-gram около 29 ГБ). **Совместимость именно этой сборки со Strata, её запуск и скорость не проверены.** Все размеры, конкретные файлы и хеши сверяем перед скачиванием.
