# Пункт 12 — Windows Monitoring

Дата: 19.11.2026. Статус: **исходник и автоматические проверки завершены; реальная Windows не тестировалась**.

## Реализовано

- Новая строго **read-only** MCP-команда `system_monitor` без аргументов. Возвращает отметку времени, текущую нагрузку CPU, доступную/занятую RAM и её процент, объём/свободное место фиксированных томов Windows, метаданные последних пяти критических/ошибочных событий из журнала `System` за 24 часа.
- Сбор Windows-данных — один статический PowerShell 5.1 запрос `Get-CimInstance` / `Get-WinEvent`. Нет выполнения произвольных команд и нет передачи команд из клиента. Ограничено 12 секундами и 40 КиБ ответа.
- NVIDIA GPU/VRAM — через `nvidia-smi` с фиксированным набором `--query-gpu` полей. Команда запускается **без shell** только по известному системному пути, лимит 5 секунд / 16 КиБ, максимум 16 GPU, строгий CSV-парсер. В ответе: модель, индекс, версия драйвера, загрузка GPU, полная/занятая VRAM и температура GPU (только если драйвер отдаёт показатель).
- Нет `nvidia-smi` / нет NVIDIA GPU / датчик не отвечает — явный `unavailable`, отсутствие чисел — `null`, а не выдуманные нули. CPU температура — `null` и статус `unsupported_without_sensor_provider`: стандартные CIM-счётчики не дают достоверную температуру процессора.
- `Win32_LogicalDisk` перечисляет **фиксированные логические тома**, но не подтверждает, какой из них SSD. Поле `media_type: "unknown"` намеренно исключает неверную маркировку HDD как SSD. Для достоверной привязки тома к физическому SSD нужна отдельная проверка на реальной Windows.
- Windows Event Log возвращает лишь ID, источник, время и уровень последних пяти событий, **не текст сообщений**, который мог бы содержать чувствительные сведения.
- MCP runtime имеет версию `0.12.0`; другие read-only инструменты и OAuth-ограничения не изменены. Скрипты и данные не пишутся на ПК.

## Справочные источники реализации

- NVIDIA `nvidia-smi` field queries и CSV: официальная NVIDIA System Management Interface документация.
- Microsoft `Win32_OperatingSystem` (`TotalVisibleMemorySize`, `FreePhysicalMemory`), `Win32_LogicalDisk` (`DriveType=3`), `Win32_PerfFormattedData_PerfOS_Processor`, PowerShell `Get-WinEvent -FilterHashtable`.
