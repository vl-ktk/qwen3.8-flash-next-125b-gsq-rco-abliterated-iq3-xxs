## 3. MCP endpoint

- Локальный адрес: `http://127.0.0.1:8765/mcp`.
- Локальная проверка: `http://127.0.0.1:8765/healthz`; публично не выставлять.
- Протокол: **MCP Streamable HTTP**, версия/совместимость выбирается и проверяется в пункте 10.
- Порт `8765` — предварительный выбор; установщик должен обнаружить конфликт, не перебивать чужие сервисы.
- Аутентификация обязательна, **никаких** безусловно открытых команд; по умолчанию `write` и административные операции выключены до реализации их защитных механизмов.
- Ограничение входящих: только loopback. WinRM/RDP/PowerShell в Интернет не публиковать.

## 4. Cloudflare и публичный URL

**Проверено через Cloudflare API 19.11.2026:** авторизован 1 аккаунт, зарегистрирован Workers subdomain `vl-ktk`, опубликованные Worker Scripts присутствуют (8 шт.), собственных DNS-зон 0, существующих Tunnel 0. Это **не означает отсутствие Cloudflare**. Публичный `workers.dev` позволяет не покупать домен.

Выбранная проектная схема **Workers VPC (бета)**:

```text
ChatGPT (MCP client)
   -> HTTPS: qwen125b-mcp.vl-ktk.workers.dev/mcp
   -> отдельный Cloudflare Worker (OAuth / разрешения в пункте 7)
   -> Workers VPC Service binding (ограничен 127.0.0.1:8765)
   -> отдельный Cloudflare Tunnel (пункт 5)
   -> MCP на ПК друга (127.0.0.1:8765/mcp)
```

- Имя нового Worker: `qwen125b-mcp`, **только проектный выбор, не существующий сервис**. Его плановый URL: `https://qwen125b-mcp.vl-ktk.workers.dev/mcp`. **Сейчас не развернут, доступность не заявляется**.
- Tunnel: `ktk-qwen125b-friend-pc` создан в **пункте 5** (ID `b49f90d5-3f8a-4aca-aeaf-c44c563b215c`), конфигурация управляется Cloudflare. Статус **inactive**, 0 подключений; привязку к Worker/VPC и Windows выполнять только в следующих пунктах.
- `Workers VPC Service`: **создан** `ktk-qwen125b-mcp-origin` (ID `01a1f103-bc58-78c2-97ef-91331e10775e`) → `127.0.0.1:8765` через Tunnel. Привязка `QWEN_MCP_ORIGIN` проверена через Cloudflare API. Доступ ограничен одним endpoint.
- Никакой DNS zone ID не нужен **для выбранного Worker `workers.dev` + Workers VPC**. В JSON `zone_id: null` означает, что зона не используется, а `tunnel_id` содержит проверенный UUID созданного туннеля. Его секреты нигде не публикуются.
- Бета-функция может измениться. Права создавать VPC Service и binding проверены успешно через Cloudflare API. Сквозная Windows-коннективность, SSE/Streamable HTTP и OAuth совместимость **не подтверждены**.
- Cloudflare Tunnel обеспечивает транспорт, **но не заменяет** OAuth, авторизацию каждого инструмента и подтверждение владельца.
- Tunnel создан в пункте 5. Worker и ограниченный VPC Service созданы/связаны в пункте 6, `workers.dev` включён. Worker до пункта 7 возвращает 401 на любой `/mcp`, ни одной команды к Windows не направляет. Проверить внешний HTTPS-ответ из текущего окружения не удалось.

## 5. Службы и права

- Windows-служба MCP: `KTKQwenMCP`, автозапуск с задержкой, включена даже при остановленной модели.
- Предпочтительная учётная запись службы: встроенная `NT AUTHORITY\LocalService` (**это не новая пользовательская учётная запись друга**). Фактические ACL, права на файлы/токены и возможность системного запуска проверять в пунктах 13, 15–18.
- У LocalService **нет автоматических прав администратора**. Административные операции пока отключены. Безопасный механизм подтверждённого повышения привилегий как часть того же продукта нужно спроектировать и испытать позднее, **не запускать весь публичный MCP от SYSTEM по умолчанию**.
- `cloudflared`: отдельный системный процесс/служба, как требует Tunnel, но **не дополнительный MCP-агент**. Проверять наличие уже установленной службы `cloudflared` до изменений; существующую службу друга не удалять и не перезаписывать.
- Windows services изолированы от интерактивного рабочего стола (Session 0); GUI-управление не обещать без отдельной проверки в соответствующем пункте.
- Локальный аварийный стоп и отзыв доступа должны работать независимо от Cloudflare.

## 6. SC117 / Strata

- Строго `SC117/Qwen3.8-Flash-Next-GSQ-RCO-abliterated-GGUF`, квантование `IQ3_XXS`.
- Движок **Strata**, но совместимость этой сборки не подтверждена. Не подменять версию или рантайм.
- Модель не входит в установщик MCP; веса скачиваются позже напрямую на ПК.
- Начальное ограничение **один активный вывод модели**; начальный контекст/параметры GPU-RAM-SSD-offload остаются неопределёнными до тестов.
- Режим по умолчанию после установки/перезагрузки **«Игры»**: модель **не** стартует самостоятельно. MCP и Tunnel остаются доступны.
- Режим «ИИ» запускается отдельной разрешённой командой; переход в «Игры» корректно завершает только принадлежащие AI-процессы, не затрагивая игры владельца.
