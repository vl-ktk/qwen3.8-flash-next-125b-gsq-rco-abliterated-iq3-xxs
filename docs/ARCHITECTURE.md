# Архитектура MCP прямо на Windows

```text
ChatGPT (собственный MCP)
      |
      v
Cloudflare Worker: qwen125b-mcp.vl-ktk.workers.dev (проектный адрес)
OAuth / защищённый HTTPS endpoint
      |
      v
Workers VPC Service binding (бета; ещё не проверена)
      |
      v
Cloudflare Tunnel (исходящее соединение)
      |
      v
Windows PC друга: MCP server on 127.0.0.1
      |
      +-- системная диагностика / PowerShell / файлы / процессы / службы
      +-- Strata / SC117 Qwen 125B
      +-- переключение ИИ / Игры
```

- Один логический продукт MCP на Windows. Отдельный устанавливаемый агент не нужен.
- Существующая учётная запись; никакой второй учётной записи Windows.
- Cloudflare Tunnel не равен авторизации. Нужны OAuth/авторизация MCP и контроль прав на каждое действие. Проверить реальную совместимость с ChatGPT.
- MCP на 127.0.0.1. Не выставлять порт напрямую в интернет и не использовать открытый PowerShell remote endpoint.
- Инструменты: system_info, app/service/process status, system monitoring, file read/write, scoped PowerShell, запускаемые программы, Strata lifecycle, модельные команды, журнал ошибок, обновление/откат.
- Разрушительные, чувствительные и мешающие владельцу операции требуют отдельного подтверждения. Экстренная блокировка доступа на ПК обязательна.
- Административные команды запускаются только с проверенным повышением прав. Не делать весь принимающий интернет-запросы процесс постоянно привилегированным без необходимости.
- Windows service и GUI: системная служба не может просто так управлять интерактивным рабочим столом Windows. При необходимости GUI нужны отдельная сессионная интеграция и тест, но не новый внешний проект.
- Изоляция режимов: MCP работает и при остановленной модели; Games Mode останавливает Strata и освобождает ресурсы, не убивает процессы пользователя.
- Установка и тесты на машине друга невозможны до передачи инсталлятора и его согласия. Статус онлайн не симулировать.

- Плановый edge Worker является HTTPS/OAuth-шлюзом на существующем Cloudflare аккаунте, **не** вторым MCP-сервером и **не** отдельным агентом на ПК друга. Поддержку Workers VPC, его права и работу Streamable HTTP нужно проверить в пунктах 5–10.
- DNS-зона не требуется для выбранного `workers.dev` + VPC маршрута. Это не доказывает, что сама связка уже работает; cloud-side ресурсов Qwen 125B пока нет.
