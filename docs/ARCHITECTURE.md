# Архитектура KTK Qwen MCP и локальной модели (Windows 11)

## Реализовано в исходниках до установки на ПК друга

```text
ChatGPT MCP client
      |
      v
Cloudflare Worker (OAuth, scopes, подтверждение владельца)
      |
      v
Cloudflare Tunnel (исходящее соединение Windows ПК)
      |
      v
KTKQwenMCP, LocalService, loopback 127.0.0.1:8765
      |  read-only диагностика, ограниченные KTK maintenance и local_ai_* tools
      v
KTKQwenUpdater, LocalSystem, loopback 127.0.0.1:18765
      |  проверенные транзакции, HMAC, ACL, откат MCP
      v
KTKQwenUserUpdater, исходный интерактивный пользователь, без elevation
      |  pinned Strata/SC117, hash/resume/pack; БЕЗ инференса
      v
Локальные файлы Strata и модели на Windows диске
```

- Установка **по умолчанию MCP-only**. В Windows Setup можно отдельно выбрать `MCP + Strata + Qwen 125B`; в этом режиме локальный GUI под исходным Windows пользователем скачивает закреплённые версии, проводит **однократную реальную генерацию для проверки** и затем останавливает **свой** runtime. GUI показывает измеренные RAM/VRAM и место C:/D:, объём/ход загрузки и даёт **«Пауза» → «Продолжить»** в том же окне без потери проверенных файлов и без новых подтверждений. После обычной ошибки можно повторить; после неопределённой остановки процесса — нельзя, пока не проведена проверка. Прерванную *собственную* установку Strata можно восстановить автоматически, готовую/чужую трогать запрещено. Если запуск, ответ или подтверждённая остановка не получены, результат установки — ошибка.
- Фоновое обновление MCP — отдельная транзакция с проверкой хешей и rollback. Фоновый пользовательский апдейтер **только готовит pinned файлы Strata/SC117**, никогда не вызывает полную установку с генерацией. Перед постановкой фоновой пользовательской задачи SYSTEM сравнивает SHA-256 установленного `Run-KTKUserUpdate.mjs` с проверенным кандидатом. **Старая задача → только MCP-update; новый Setup обязателен для обновления пользовательского runner.** Подготовка из MCP `local_ai_install_resume` и `local_ai_repair` также не запускает модель.
- Вход через Cloudflare Tunnel сам по себе не является авторизацией; Worker ограничивает права OAuth, операции через SYSTEM updater ограничены HMAC/ACL и списком операций. Нет произвольного PowerShell/командного shell из MCP; LocalService не превращается в общую административную консоль. Удалённые операции не обходят UAC, Defender и права Windows.
- Часть локального Strata выполняется от имени исходного интерактивного Windows-пользователя. Задача Task Scheduler с InteractiveToken требует активного входа пользователя; при отсутствии сессии выполнение откладывается. Служебный MCP может продолжать работать без модели.

## Ещё не реализовано

- **ПК друга не проверен:** CUDA/драйвер, фактическая генерация SC117, RAM/VRAM, завершение процесса и поведение после перезапуска Windows 11 должны быть подтверждены отдельно после разрешения владельца. Установщик пока тестовый, не подтверждён для реального GPU.
- **Панель KTK Local AI — этапы 9–10 плана:** после первой установки одна локальная адаптивная панель для чата, истории и мониторинга; только две явные кнопки «Загрузить модель» / «Выгрузить модель». Обычный чат, health, обновление, запуск Windows, таймер или открытие страницы **никогда** не запускают и не выгружают модель. Выгрузка должна дождаться текущего ответа и остановить только свою сессию.
- **Мобильный доступ** будет через ту же панель по отдельному защищённому Cloudflare Tunnel + Access с owner allowlist, обязательной проверкой сессии/токена на origin, CSRF и потоковых соединений. Ни Strata (`8080`, `18764`), ни MCP (`8765`), ни updater (`18765`) не открываются напрямую в интернет.

Порядок, критерии готовности и границы разрешений: [LOCAL_AI_MANUAL_CONTROL_PLAN.md](LOCAL_AI_MANUAL_CONTROL_PLAN.md).
