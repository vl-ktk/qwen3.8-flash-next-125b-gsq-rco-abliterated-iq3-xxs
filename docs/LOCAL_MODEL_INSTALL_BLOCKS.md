# Local SC117 IQ3_XXS installation via Windows MCP — implementation blocks

## Target and sources (verified 2026-11-20)

- Machine **to be installed later**: Windows, i9-12900K, RTX 3090 Ti 24 GiB VRAM, 64 GiB RAM, NVMe drives C: and D: (actual disk space and installed software not yet measured).
- Exact model: `SC117/Qwen3.8-Flash-Next-GSQ-RCO-abliterated-GGUF`, `IQ3_XXS`, both shards. Model repository rounds them to **47.34 GB + 28.80 GB = 76.14 GB**: https://huggingface.co/SC117/Qwen3.8-Flash-Next-GSQ-RCO-abliterated-GGUF
- Engine: Strata. This **particular** abliterated model needs its *own* native pack generated from its GGUF; an official-model pack has incompatible offsets. Also fetch the published Strata MTP runtime (`strata/rt`). Source: https://huggingface.co/SC117/Qwen3.8-Flash-Next-GSQ-RCO-abliterated-GGUF/blob/main/strata/README.md
- **130 GB recommended free on one fixed volume** is a conservative planning allowance, not an upstream minimum or a promise of successful download/pack. The true required space must be measured during B/C before downloading. Storage-bus inventory alone cannot map a specific drive letter to an NVMe device.
- Cloudflare Worker is not an inference host: only the future local Windows Strata process can run inference. Do not quietly switch to llama.cpp/remote APIs/a different quantization.

## A — Read-only inventory and plan (source implementation)

1. `pc_preflight()`: Windows edition/architecture, CPU/threads, RAM total/free, Windows service execution context, NVIDIA GPU/driver/VRAM. Missing data explicitly marked unknown; no AVX/CUDA execution test.
2. `storage_check()`: bounded fixed-volume inventory, free bytes, recommended-space candidates, physical media/bus information **without asserting a volume-to-physical-device mapping**.
3. `runtime_check()`: Strata machine-wide HKLM uninstall registrations, exact process names, NVIDIA driver inventory. Per-user installations, Python venv and CUDA code execution **not** checked. A missing registration is *not* proof of absent Strata.
4. `installation_plan()`: reuses these three live read-only checks, always reports **no writes**, target/model/space estimates, missing evidence, and six explicit unstarted next steps. Fails closed on partial observations.

All four tools have empty parameter objects (`additionalProperties: false`); PowerShell scripts are static, non-interactive, bounded, run without inherited OAuth/environment secrets or a shell. There is **no** execute/install/download/modify/PowerShell tool added. No machine has been tested by introducing this source code; tools only become available after a future signed/reviewed Windows MCP update and an MCP tool-list refresh.

## B — Pinned Strata Terminal and GPU engine installer (source implementation)

- **Publisher:** `Niko1221/Strata` GitHub release [v0.2.17](https://github.com/Niko1221/Strata/releases/tag/v0.2.17), released 2026-11-20. It ships an independently versioned **Control 0.1.63** and Windows GPU engines. Exact asset names, sizes and SHA-256 digests are pinned in `src/windows/strata-runtime.lock.json` from release metadata.
- `src/windows/strata-installer.mjs`: `strataInstallPlan()` is always read-only; `installStrata()` requires local installer approval and Windows x64. `scripts/Install-KTKStrata.mjs` provides the future one-click wizard's static actions `--plan`, `--install --installer-approved` and `--recover --installer-approved` (no arbitrary paths or commands accepted on its CLI).
- Downloads only the **pinned official 16,171-byte `install.ps1`**, validates SHA-256 before running; no `irm | iex` or GitHub `latest` URL. The vendor script fetches the Terminal package and checks its SHA-256 and the signed Strata feed. It receives `STRATA_FEED=https://github.com/Niko1221/Strata/releases/download/v0.2.17`, `STRATA_NO_PATH=1`, `STRATA_DATA_DIR=<current-user LOCALAPPDATA>/KTK/Strata` in a restricted subprocess environment.
- Invokes the bundled Python interpreter directly (no `cmd.exe` shell), checks `strata.py --version`, runs the upstream **signed engine updater** (`update --no-control --feed ... --output json`), and queries installed engine inventory. No model weights are downloaded by this block. NVIDIA driver/CUDA compatibility and actual generation are *not* proven until model startup in D/E.
- A fresh install uses an exclusive KTK-owned directory and a marker. On failure, cleanup touches **only that newly created KTK runtime tree**; unknown existing folders or user Strata folders are never overwritten. A separately approved recovery removes only an abandoned `installing` KTK tree, never a `ready` one. On repeated success the module is idempotent.
- The staged Windows package contains the lock, module and wrapper. **Existing Setup.exe does not yet invoke this new stage**, because B/C/D must be connected to one integrated acceptance wizard in E. The remote Windows MCP remains read-only. No admin service, Windows host, Cloudflare or model is modified by these source changes.
- The repo's Windows CI runs offline mocks of the installer and resolves the packaged `--plan` on native Windows; it does **not** run the signed 740 MB engine download, a real vendor installation, or inference on the owner's machine. These are explicitly deferred to the combined acceptance test.

## C — SC117 IQ3_XXS + Strata MTP download and native pack (source implementation)

- **Model pin:** SC117 Hugging Face repository revision `90a3350cd800ec1fe0d1660a38414ad9e985782f`, exact two `IQ3_XXS` shards (47,342,144,896 + 28,800,138,432 bytes) and four Strata `strata/rt` files. All six filenames, exact sizes and SHA-256 fingerprints are pinned in `src/windows/sc117-model.lock.json`. The 1,880-byte `dense.txt` fingerprint is computed from the upstream CRLF payload and must be confirmed by the future live download; a mismatch stops before packing.
- **Packer pin:** Official `Niko1221/Strata` v0.2.17 tag `terminal/tools/iq_pack.py`, 44,648 bytes and pinned SHA-256. [The upstream Terminal package includes this installer tool and its Python dependencies](https://github.com/Niko1221/Strata/blob/v0.2.17/tools/packaging/package_terminal.py). `prepareSc117Model()` checks the executable, tool integrity and installed KTK Strata marker before attempting any model write.
- **Local installer entry:** `scripts/Prepare-KTKSC117.mjs` provides only `--plan` (always read-only) and `--prepare --installer-approved`. It is packaged into the Windows MCP ZIP but **not** exposed as a remote mutating MCP method and **not** called by Setup.exe before integrated block E.
- **Storage:** only local fixed Windows `C:`/`D:` NTFS/ReFS volumes are considered, preferring D: with adequate measured space. Initial download requires the six download sizes plus a conservative 20 GB pack/workspace allowance (at least 96.97 GB measured free); **130 GB remains the recommendation**, not an asserted upstream hard minimum. A matching incomplete KTK installation stays on its original volume and counts its existing partial bytes. No claim is made that C:/D: correspond to NVMe before actual host observation.
- **Transfers:** only pinned HF `/resolve/<full-commit>/...` HTTPS assets, final redirect host allowlist, byte-range resume with strict 206/Content-Range checks, explicit download metadata ownership, streaming writes and whole-file SHA-256 before atomic file activation. Transient failures leave `.part` for another one-click attempt; checksum failures discard only the unverified KTK `.part`. Existing unknown files/folders are never overwritten.
- **Pack:** after verifying all downloads, run exactly the pinned Terminal Python and `tools/iq_pack.py --gguf <SC117 shard 1> --out <KTK pack staging>` with no shell or inherited OAuth credentials. The second shard stays next to the first, as the upstream tool requires. Validate `index.txt`, `dense.bin`, `native_experts.txt` and exported tokenizer before activating a separate SC117 pack. The Strata MTP path is `<KTK model root>/mtp/rt`, distinct from the native pack. A failed pack removes only its KTK-owned transient pack directory, preserving verified shards/MTP for retry. A completed model remains idempotently available without rehashing 77 GB on every invocation; status explicitly says that subsequent checks are not rehashes.
- **Verification boundary:** local mock tests cover resume, integrity rejection, disk selection and pack command. Windows CI tests offline on an ephemeral Windows runner and executes bundled `--plan`; neither CI nor the owner has downloaded ~77 GB, run the authentic packer on the target hardware or generated tokens. These remain part of the future integrated acceptance. Cloudflare, Netcup and existing Windows installations are unchanged.

## D — Local Strata inference verification and guarded lifecycle (source implementation)

- `src/windows/sc117-inference.mjs` and `scripts/Test-KTKSC117.mjs` add a **read-only `--plan`** and a locally approved `--test --installer-approved`. The live action is not an MCP tool and is not called by the current Setup.exe; block E must connect the stages in the one-click installer.
- Refuses non-Windows x64 execution, missing explicit approval, unexpected KTK Strata 0.2.17/CUDA or SC117 ready markers, symlinks, and absent shards/MTP/native pack. The stage trusts the verified download marker from C and checks existence/type, but **does not rehash ~77 GB** before every start.
- Builds a separate KTK-owned Strata run config using `component:strata-engine`, native **SC117** shard 1 and `--ple-gguf` shard 2, SC117 pack/tokenizer, and four-file MTP runtime. It never silently selects a different quantization or online inference. [Strata v0.2.17 docs](https://github.com/Niko1221/Strata/blob/v0.2.17/docs/DETAILS.md), [SC117 Strata layout](https://huggingface.co/SC117/Qwen3.8-Flash-Next-GSQ-RCO-abliterated-GGUF/blob/main/strata/README.md).
- Only listens on **127.0.0.1:18764**. Strata profile has `offline: true`, `parallel: 1`, `max_queue: 0`; context 8192 tokens, 2048 MiB GPU reserve, conservative resident RAM budget `min(40 GiB, floor(total RAM GiB) - 24 GiB)` with refusal below 8 GiB. These are provisional starting settings; they do **not** guarantee smooth gaming or runtime compatibility until the real GPU test.
- Uses the official Strata **owned runtime** (`runtime start/status/verify/stop`), generating a fresh local-only API bearer token for this session. Refuses an existing active server or unrelated saved profile; requires the same owner and instance IDs before health/inference; verifies a loaded `/health` and an OpenAI-compatible chat completion; sends Strata's guarded `runtime stop --if-owner-id --if-instance-id`, and reports a stop failure loudly rather than silently leaving GPU work behind.
- Tests and Windows CI use offline fixtures/mocks and `--plan` from the bundled ZIP; they do **not** start a real Strata service, allocate a real GPU or download model weights. A live inference success cannot be claimed yet.
