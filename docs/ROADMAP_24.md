## Этап II. Cloudflare и соединение (5–9)
- [ ] **5. Создать отдельный Cloudflare Tunnel** только для ПК друга. Не менять действующие туннели.
- [ ] **6. Настроить HTTPS/маршрутизацию** до локального loopback MCP без открытых входящих портов.
- [ ] **7. Реализовать совместимую с ChatGPT авторизацию и контроль инструментов.** Проверить защищённый MCP на фактическом коннекторе и отказ посторонним.
- [ ] **8. Реализовать одноразовую привязку устройства.** Ключ генерируется на ПК, первичное одобрение владельцем; в установщике нет постоянных ключей. Безопасные повторное подключение и отзыв доступа.
- [ ] **9. Провести тесты облачной части до передачи.** HTTPS, недействительные токены, replay, временная недоступность ПК, повторное соединение.

- [ ] **11. Добавить инструменты Windows.** PowerShell с политикой допуска; информация о системе; файловые операции; процессы, программы и службы.

- [ ] **13. Добавить администрирование.** Статус, управление жизненным циклом, обновление, health-check, безопасное восстановление после сбоя, подтверждаемая перезагрузка.
- [ ] **14. Разграничить привилегии и защитить команды.** Аудит, согласование разрушительных действий, ограниченный системный доступ, аварийный отзыв.

- [ ] **17. Реализовать обслуживание.** Проверяемое обновление, откат предыдущей версии, исправление установки и удаление/отвязка.

## Этап VI. SC117 и режимы (22–24)
- [ ] **22. Проверить, скачать и установить Strata + SC117 125B IQ3_XXS.** Релизы, формат, sha256, совместимость с Windows, загрузка и тест GPU/RAM/SSD offload; зафиксировать невозможность, если несовместимо, без тайной подмены.

## Приёмка
Система считается готовой только после: (a) установки одним пакетом, (b) живых команд ChatGPT → Windows, (c) авторизации/отзыва, (d) запуска именно утверждённой SC117 через подтверждённый runtime, (e) освобождения ресурсов для игр.
