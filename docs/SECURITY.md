# Безопасность, права и привязка

- Владелец ПК выразил согласие на удалённый доступ и администрирование.
- В GitHub, инсталляторе, протоколах тестов и чате **не хранить** пароли, приватные ключи, действующие Tunnel tokens, OAuth refresh tokens и иные секреты.
- MCP endpoint принимает только аутентифицированные команды и проверяет авторизацию на каждый инструмент. Cloudflare Tunnel/HTTPS без auth недостаточны.
- Рекомендуется device-bound регистрация с одноразовым кодом и отзывом токена; срок, криптография и ключевой обмен определяются в реализации и проверяются тестами.
- Постоянные полномочия Windows не выдаются всем операциям по умолчанию; повышение прав только на те инструменты, где это необходимо.
- Для удаления личных данных, отключения защиты системы, установки неизвестных бинарников, перезагрузки, принудительного закрытия чужих процессов и затрагивающих игру действий: явное подтверждение владельца. Иметь локальную кнопку / команду немедленной остановки MCP, независимую от сети.
- Аудит: время, идентификатор запроса, разрешённое действие, статус и код ошибки. Не логировать чувствительное содержимое.
- Ограничение размера команд/ответов, rate limit, тайм-ауты, защита от повторной передачи запросов.
- Разворачивать MCP только на loopback. Не открывать RDP/WinRM/SSH/PowerShell в публичный интернет.
- Проверить восстановление после недоступности сети, истечения токена, отзыва доступа и падения Windows service.
- При отсутствии совместимого механизма OAuth для ChatGPT не отключать авторизацию ради обхода. Отдельно описать блокер.
