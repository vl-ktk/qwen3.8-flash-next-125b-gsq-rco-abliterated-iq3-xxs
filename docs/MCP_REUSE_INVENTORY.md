## Что переносим в наш проект

**Сейчас:** только этот документ инвентаризации, ссылки на исходники, матрицу решений и тестовые требования. Исполняемый код из иных репозиториев **не копировался**.  
**Позже:** допускается повторная реализация конкретных механизмов с изоляцией от чужих пользователей, лицензий и секретов, после отдельного аудита зависимостей. Переиспользование части кода возможно только после проверки юридической и технической пригодности и переноса в **этот** репозиторий.

## Критические ограничения

- Нельзя использовать существующий Instagram OAuth как авторизацию Windows MCP.
- Нельзя переносить HMAC secret из существующего Worker, токены Cloudflare или ключи Instagram.
- Windows DPAPI, привязанный к пользователю, и Windows service под другой учётной записью могут иметь разные криптографические контексты. Конкретное решение об учётной записи службы фиксируется на пункте 4/15, тестируется на Windows.
- Cloudflare Tunnel даёт транспорт, **но не авторизует команды**.
- Привилегированный PowerShell от удалённой модели требует независимой проверки прав, подтверждения критичных операций и локального выключателя.
- Нет доказательства переносимости готового Linux sandbox из `ai-agent-engine` в Windows.
