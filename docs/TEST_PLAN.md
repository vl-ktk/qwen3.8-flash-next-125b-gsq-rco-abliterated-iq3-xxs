# Тестирование и критерии готовности

## До передачи другу
- Юнит-тесты MCP инструментов и контроля доступа, неправильные аргументы, audit.
- Тесты HTTPS/OAuth с реальным тестовым коннектором ChatGPT.
- Тест Cloudflare Tunnel: только локальный MCP, отсутствие доступности без auth, reconnect.
- Тест привязки: валидный/просроченный/повторный код, отзыв и повторная выдача, отсутствие секретов в инсталляторе.
- Windows VM: чистая установка, перезапуск, запрет прав, отключённая сеть, повторная установка, обновление, откат, удаление.

## На Windows друга
- Подтвердить PC/GPU/RAM/SSD/Windows/драйвер версии, файловую систему, дисковый запас.
- Через ChatGPT выполнить read-only запрос характеристик и ограниченную тестовую PowerShell-команду.
- Проверить безопасное тестовое изменение и откат, подтверждение чувствительной команды, отказ чужого подключения.
- Перезагрузка с согласия владельца, автозапуск MCP и облачного канала.
- Проверить фактическое завершение/невозможность выполнения при локальном отзыве доступа.
- SC117/Strata: целостность файлов, первый запуск, ответы, скорость, пиковые RAM/VRAM, стресс контекста и чистое завершение.
- ИИ → Игры → ИИ: отсутствие самовольного вмешательства в игры, освобождение видеопамяти, сохранение MCP канала.

## Release report
Для каждой выложенной версии: исходный SHA, предыдущая версия/откатный SHA, тесты реально пройденные и не пройденные, адрес опубликованного релиза/артефакта (без секретов), ошибки и ограничения.

До успешных живых тестов не объявлять устройство подключённым и модель запущенной.
